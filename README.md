# cnclightbit.com

Website for CNC LightBit LLC, Lucedale, MS.

- `index.html` is the whole site: pages, t-shirt ordering, the knife designer, the cart and shipping rates.
- `_headers` holds the security settings that Netlify reads.
- `designs/` holds the t-shirt and knife images.

Netlify publishes this repository automatically. Every change saved to the `main` branch goes live within a minute or two.
Order and contact forms use Netlify Forms, and "Form detection" must stay enabled in Netlify (Project configuration → Forms).
